## What it is

A 3D tower-defence game for our graphics course. You hold off waves of orcs with turrets and traps.

## How it's built

About 8,200 lines of Python on PyOpenGL and GLUT, with no game engine. We built every model, the orcs included, from cubes, spheres and cylinders.

We started a browser port in React Three Fiber later and never finished it. The Python game is the real one.
